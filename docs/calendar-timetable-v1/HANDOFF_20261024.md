## 생성 그룹 폼 편집 — 이전 배포 기록

사용자 결정에 따라 다중 요일 블록의 원래 생성 그룹을 유지한다. 기존 TimetableService,
CalendarCreationOperations, BlockDialog, TimetableWorkspace, TimetableGrid를 확장했다.
새 관리 화면이나 반복 일정 엔진은 추가하지 않았다.

- 그룹 멤버를 열 때 최신 서버 목록으로 실제 요일을 불러온다. 기존 폼에 `함께 만든 블록 N개 수정`을 표시한다.
- 그룹 저장은 전체 멤버 ID·version 비교 후 단일 트랜잭션으로 공통 필드와 요일을 조정한다.
  유지 요일 ID 보존, 추가 요일 새 ID, 해제 요일 soft delete, 한 요일만 남아도 그룹 유지다.
- 개별 드래그·리사이즈·삭제는 해당 멤버만 분리한다. 삭제 Undo는 같은 ID를 미연결 상태로 복원한다.
  개별 복제는 미연결이고, 전체 시간표 복제는 새 그룹 ID로 내부 관계만 복사한다.
- 폼 취소·오류·409 시 입력을 보존하며, 저장 중 중복 제출을 막는다. 같은 본문 재시도는 같은 키를 사용한다.
- API: `PUT /api/calendar/timetables/{id}/block-groups/{group}`, 필수 Idempotency-Key,
  `{weekdays,block,members:[{id,version}]}`. 성공 응답은 해당 시간표의 전체 활성 blocks다.

DEV 코드 커밋 `6727184a5ce9a1530b63bdcd26b41e8af30e825a`, PROD 코드 커밋
`da2454fbd4495a2cd83cbe348716a838fa615526`. 다른 Sleep/Reflection 작업과 기본 체크아웃의 기존 수정은 보존했다.

## 구현 결과

기존 캘린더 안에 날짜 없는 월~일 시간표 탭을 추가했다. 시간표 생성·정보 수정·정렬·전체 복제·보관·복원,
설명/목표/메모가 여러 줄로 표시되는 상세 카드, 독립적인 좌우 패널 접기와 기본 배치 복원을 제공한다.
카드와 보조 정보는 같은 초안을 사용한다. checklist 항목 수정·순서·체크 상태도 저장한다.

블록은 클릭·드래그 생성, 다중 요일 생성, 요일 이동·리사이즈, 상세 폼, 복제·삭제·실행 취소를 지원한다.
15분 스냅과 1분 직접 입력, 겹침 레인, 월→화/일→월 자정 연결, 명시적 다음 날 종료와 24시간 길이를 처리한다.
저장 실패는 이전 배치로 복구하고 버전 충돌은 초안을 보존한다. 기존 날짜별 일정·Actual·통계는 변경하지 않는다.
