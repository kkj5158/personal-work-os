## 구현 진입점

- `frontend/app/calendar/page.tsx`: 기존 세 내부 보기 유지, day/week/month 및 공유 날짜·필터·URL 상태.
- `DailyInputCenter.tsx`, 기존 `DailyReflection.tsx`: V96의 canonical session을 inline로 사용. WORK score와 두 checklist는 각각 자기 provider에 저장한다.
- `DailyChecklists.tsx`, `components/checklist-core/ChecklistDayList.tsx`: 기존 Grid/mutations의 singleDay 표시. 실패 후 flush가 이동을 막으며 같은 작업을 재시도한다.
- `CalendarRetrospective.tsx`, `reviewModel.ts`: 월 4/5/6주 전체 카드, 주 요약·Actual pattern, 주간 편집기와 평균/coverage.
- `CalendarReviewService/Controller`, `CalendarReviewWorkMinutes`: owner-scoped range/weekly CAS, source identity 기반 WORK projection 집계.
- `V97__calendar_weekly_reviews.sql`: 새 주간 테이블만. V95 Sleep/V96 daily reflection을 편집하거나 중복 생성하지 않는다.

Canonical NOTE `content`와 하루 annotation `memo`는 독립이다. 완료된 회고의 annotation 편집은 기존 정책대로
content/status/snapshot을 유지한다. 주간 점수·감정은 직접 입력이며 일 평균으로 자동 채우지 않는다.
WORK score의 부분 갱신은 WorkRecord를 자동 생성하거나 자식 시간을 재작성하지 않는다.
DIET memo 부분 갱신은 같은 check의 state를 갱신하지 않는다.
