## 표시·조회·저장

대표 계좌는 최대 열 개이며 기본 다섯 개만 표시합니다. 이름은 선택 사항이고 최대 다섯 행·행마다 세 개입니다. 3+3에서도 두 번째 행의 두 개만 먼저 보입니다. 더 보기는 행 맥락을 유지합니다. 배치 편집은 모든 선택 계좌, 끌기·키보드 이동, 저장·취소, 버전 충돌 시 초안을 지원합니다. 기존 순서만 읽어도 DB에 쓰지 않으며 순서만 보내는 요청으로 저장한 배치를 지우지 않습니다.

같은 조회의 갱신은 기존 자료와 마지막 성공 시각을 유지합니다. 새 조회·소유자·세션의 자료와 늦은 응답은 분리합니다. 제목·메모·최종 분류·상세 저장은 같은 거래의 최신 버전을 조정합니다. 제목·메모만 저장하면 검토를 완료하지 않습니다. 최종 분류를 저장하면 검토를 완료합니다. 저장 응답을 잃으면 같은 요청의 결과를 조회합니다.

기본 표시 통화는 KRW입니다. 실제 금융 통화와 원본을 보존하며 환산·통화 역채움·자료 없음의 0 처리는 하지 않습니다. 잔액 기준점이 없거나 해당 합계에 외화 자료가 있으면 그 범위의 합계는 확인 필요로 표시합니다.

## 금융·분류 의미

RAW, 금융 사실·출처, 분류 의미는 별도 계층입니다. 분류 API는 금융 금액·날짜·계좌를 수정하거나 RAW를 원장 거래로 만들거나 이체를 연결하지 않습니다. 자동 판단 실패·보류는 장부 제외가 아닙니다. 원문·이체 후보·환불·대출 분해는 기존 금융 확인 경로를 사용합니다.

명시적인 현재 페이지 분류 저장은 서로 다른 최대 50개 ID와 현재 버전의 원자 묶음입니다. 하나라도 충돌하면 전체를 적용하지 않습니다. 독립 자동 작업과 명시 승인한 과거 작업은 거래별 결과를 기록합니다. 취소는 이후 직접 수정·복구 불가를 미리 제외한 적격 묶음만 원자적으로 복구합니다. 새 충돌은 전체 미적용입니다. 제목·메모·금융 원본과 별도의 이후 검토 결정은 보존합니다.

우선순위는 현재 직접 지정 보호, 같은 계좌·유형·거래처·구매 맥락의 최신 유효 직접 수정, 승인 규칙, AI 판단입니다. 단순 확인·자동 출력·취소한 결과는 사람의 수정 학습이 아닙니다. 현재 유효한 중·소분류 ID만 사용합니다. 중분류만 적용은 실제 중분류 ID를 저장하며 가상 ‘소분류 없음’을 저장하지 않습니다.

이번 거래만 반영은 재저장해도 향후 참고 제외를 유지합니다. 제외 해제는 미래 참고에만 영향을 줍니다. 구매 의미가 그대로인 작은 철자 수정으로 자동 재판단하지 않으며, 현재 직접 지정은 늦은 AI가 덮어쓰지 않습니다.

T27의 동일 본문·경로·시각·잔액을 가진 여러 원문 키는 모호한 후보 그래프로 처리하여 새 금융 사실을 만들지 않습니다. 원문은 보존합니다. 별도의 시간·잔액 흐름이 있는 실제 반복은 유지합니다. 종료·사용자 결정 이후 늦은 근거는 명시적인 금융 확인을 요구합니다.

## 조사·대출

잔액 조사 스냅샷은 같은 소유 계좌·실제 통화·기준점·마감 시각에서 읽습니다. 수동 사실과 추가 알림을 중복 움직임으로 세지 않습니다. 전체 등록 합계와 명확한 미등록 후보의 참고 합계는 열 개 증빙 페이지와 독립적입니다. 스냅샷 토큰의 버전이 달라지면 새 조사를 요구합니다. 부족·부분·상충 근거는 완전 검증을 주장하지 않습니다.

조사는 읽기 전용이며 자동 잔액 조정·새 은행 조회·독립 관측 저장 모델을 추가하지 않습니다. 조정은 기존 금융 확인·사유·버전 보호를 사용합니다. 대출 총 납부는 원금+이자+수수료이며 확정 원금만 부채를 줄입니다. 없는 일정·분해는 0·예측·연체가 아닙니다.

## 대화·규칙·거래처·보관

대화·참고 항목·미적용 규칙 초안은 서버에 보존합니다. 제공자가 준비되지 않았거나 실패하면 내부 근거 설명과 그 제한을 표시합니다. 대화와 초안 저장은 실행 규칙이나 거래를 바꾸지 않습니다. 모의 또는 준비된 제공자는 현재 허용한 ID·최소 구매 의미만으로 미적용 제안을 만들 수 있습니다.

규칙 승인은 선택한 최신 초안·원본·영향을 다시 확인하는 원자 묶음입니다. 과거 거래에는 자동 소급하지 않습니다. 과거 적용은 규칙·계좌·기간의 별도 미리보기와 승인을 요구하며, 작업과 거래별 결과를 서버에 기록하고 50개씩 진행·일시 정지·재개·실패만 재시도를 지원합니다.

거래처 연결은 이번 거래가 기본입니다. 기존 결제명·별칭 연결을 재사용하고 명시적인 연결 해제로 상속을 막습니다. 결제명·별칭 전체 변경은 별도 대상·관련 규칙·버전 검토 후 적용합니다. 현재 분류·금융 사실·기존 승인 규칙은 연결 변경만으로 수정하지 않습니다. 중개 결제명 전체를 한 사업체로 고정하지 않습니다.

외부 사업체 검색은 기본 꺼짐입니다. 꺼짐에서는 신규 요청과 새 분류의 검색 캐시 사용을 막고, 이미 저장한 역사적 근거는 읽을 수 있습니다. 실제 개인 자료로 제공자 검증을 하지 않습니다. 기존 하루 열 회·25초·자동 재시도 없음·24시간 캐시·출처 검증을 유지합니다. AI 분류·대화 제공자는 준비 여부를 별도 설정하며 검증·소유자 DEV 열람에서는 비활성화합니다.

대화 본문은 마지막 활동 후 90일, 미적용 초안은 명시적 폐기까지 보관합니다. 변경 근거는 최소 1년이고 분류 이력은 50개씩 추가 조회합니다. 보관 종료가 금융 원본·장부·현재 분류를 삭제하지 않습니다. AI 표면의 300px 패널과 1200px 기준은 실제 내용 폭에서 적용하며 Transactions와 Category Manager의 기존 틀은 유지합니다.
