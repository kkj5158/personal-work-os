# MONEY 검토 필요 간소화 — 2026-10-13

소유자가 승인한 M-001/M-002/M-004/M-005/M-006의 제품 계약이다. 기존
`money-trust-pass.md`의 일반 거래 자동 승인 보수성 및 Review 우측 패널 요구는
이 범위에서 아래 정책으로 대체한다. 소유권, 재무 원장, 중복·이체 보호,
원문 보존, 기존 Android API는 유지한다. M-003 성능 감사는 별도 작업이다.

## 금융 승인과 통화

검증된 국내 은행 알림 형식, 방향·양수 금액·시각, 확인된 소유 계좌, 원화,
기존 식별·중복 근거를 갖춘 일반 수입·지출은 가계부에 등록할 수 있다.
거래처 문자열은 구조화된 금융 근거를 보완하며 금액이나 계좌를 대신하지 않는다.
지출 분류가 없어도 `미분류`로 등록한다. 승인에 유료 AI 분류를 요구하지 않는다.

미확인 외부 상대 계좌 번호만으로 충분히 입증된 거래처 지출을 막지 않는다.
소유 계좌 미확인, 모호한 송금·이체·환불·대출, 중복 가능성, 충돌 근거,
지원하지 않는 형식·통화는 검토에 남긴다. 기존 이체 대기 시간과 매칭 안전
경계를 지키며, 이미 등록된 거래와의 중복도 다시 검사한다.

국내 원화 형식이 검증된 후보의 통화 누락은 원화로 해석·표시한다.
명시된 통화는 보존하고 외화를 환산하거나 원화로 덮어쓰지 않는다.
원화 가정으로 소유 계좌나 잔액 기준을 만들어 내지 않는다.

기존 검토 대기 데이터는 읽기 전용으로 재평가한다. 신규 수신의 자동 등록과
기존 대기의 명시적 사용자 처리를 구분한다. 배포·조회는 기존 대기 항목의
자동 확정, 삭제 또는 원장 backfill을 수행하지 않는다.

## 표와 명령

Review의 거래처는 굵은 첫 줄, 알림 제목은 작은 보조 줄이다.
실제 거래처가 없으면 `거래처 미확인`을 표시한다. 알림 제목을 거래처로
대체하지 않는다. 일시·금액·소유 계좌·방향·상태·검토 사유를 표에서 확인한다.
정상 Review 흐름에서 우측 금융 확인 패널 및 지출 분류 편집을 사용하지 않는다.

각 행과 일괄 처리의 기본 동작은 `가계부 이동 / 보류 / 비거래 처리`다.
가계부 이동은 화면 이동이 아니라 기존 금융 확인 서비스를 호출하는 처리다.
필수 금융 근거가 미해결이면 행에 차단 사유를 표시한다. 비거래 처리는 기존
보호 계약에 따라 원문과 이력을 남기며 등록된 금융 이동을 조용히 취소하지 않는다.
보류는 기존 보류 탭과 복구 의미를 유지한다.

`처리 대상 선택`과 `선택 항목 일괄 처리`는 별도 영역이다.
현재 페이지·필터 전체 선택, 선택 해제, 선택 수와 화면 밖 선택 수를 제공한다.
페이지 이동·새로고침은 선택을 보존하고 필터 변경은 이전 범위의 오처리를
방지한다. 일괄 미리보기는 고정 ID, 적격·제외 수, 사유와 금융 영향을 표시한다.

## 영속 결과·실패·복구

기존 `/api/money/review/batches/preview`, `/execute`,
`/outcomes/{requestId}`를 확장한다. `MOVE_TO_BOOKKEEPING`은 추가 동작이며
기존 `DEFER`, `NON_TRANSACTION`, `REOPEN` 계약을 유지한다.
각 금융 명령은 소유자 잠금과 최신 금융·버전 검증을 거친다.
여러 독립 항목의 실행은 항목별 확정 결과를 가지며 전체 원자성을 주장하지 않는다.

서버가 확정한 성공 항목만 활성 표와 선택에서 제거한다. 실패·충돌은 남기고,
응답 손실은 원래 요청 ID로 결과를 조회한다. 미확인 요청을 새 요청으로
자동 재시도하지 않는다. 같은 요청 재실행과 반복 클릭은 거래를 추가하지 않는다.
기존 Undo 가능 범위는 보존하고 금융 등록에 임의 Undo를 추가하지 않는다.

현재 표는 확정 결과에 따라 갱신하고 관련 가계부·재무 조회를 무효화한다.
처리마다 전체 페이지를 재시작하지 않는다. 실제 릴리스·QA·대기 재평가 결과는
별도 한국어 릴리스 보고서에 정확한 리비전과 증거로 기록한다.
