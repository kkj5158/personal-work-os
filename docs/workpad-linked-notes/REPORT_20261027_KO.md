## 복구·인계·정리

새 migration이나 일괄 데이터 변환은 없다. 장애 시 현재 운영의 MONEY·STUDY를 보존하면서 이번 WORKPAD만 되돌린 소스로 roll-forward하는 편이 안전하다. 오래된5146fa4/9fadeb8 source pin을 그대로 재적용하면 최신 MONEY·STUDY가 되돌아갈 수 있으므로 사용하지 않는다. 실제 데이터가 손실될 수 있는 DB rollback·일괄 정정은 이 작업에 포함하지 않는다. WORKPAD 구조로 저장한 노트는 버전 주석을 이해하는 호환 editor로 유지한다.

검증 DB·서버와 자체 Playwright 탭은 정상 종료했다. 기본 작업 사본의 기존 변경과 다른 작업의 브랜치·탭은 보존했다. 운영 후보 checkout은 앱의 현재 primary checkout이라 archive가 차단되어 보존한다. 이 사유로 도구 제한을 우회해 삭제하지 않았다. 해당 checkout은 검증된 origin/prod에 detached 상태이며 임시 prod 로컬 branch는 삭제했다. 별도 구현 worktree는 최종 인계를 원격 dev에 반영한 후 archive한다. 그 최종 결과와 branch 정리는 동일 Drive 인계에 갱신한다. 임시 원격 브랜치는 만들지 않았다.

기존 Drive 문서 ID와 증거 ZIP ID를 갱신하며 공유 권한이나 다른 사람에게 알림을 변경하지 않는다. 증거: `docs/workpad-linked-notes/evidence/`의 배포 상태, resumed DEV 관찰, 운영 smoke, 원본 QA 실패/별도 postcheck, 테스트·빌드 및 이전 합성 screenshot.
