# WORK FLOW V1 — UI Reference Pack

## Target repo location
`docs/work-flow`

## Included references
1. Today Workpad — Daily work journal / block editor / checklist / images / shortcut rail.
2. Projects — Project → Phase → WorkTask hierarchy and context rail.
3. Timeline — Month-based Project / Phase / WorkTask timeline with direct drag/resize planning UX.
4. To-do — Project-grouped WorkTask execution list.
5. To-do View Settings — project group ordering, sorting and display settings.

## Usage rule
These files are UI/UX references, not pixel-perfect implementation contracts.
When implementation prompts are prepared, instruct the coding agent to read the assets from `docs/work-flow` and preserve the existing Personal OS / NOTE SYS visual language.

## Current V1 boundary
- WORK FLOW is an independent top-level system.
- Core pages: Projects / Timeline / To-do / Today.
- Today is the primary UX investment area.
- Existing top-level Calendar integration is excluded from this V1.
