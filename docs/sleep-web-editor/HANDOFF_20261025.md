## 주의할 기존 계약

서버 주수면 수동 수정은 오래된 revision의 명시 입력도 병합한다. 웹 최초 저장 사전 조회는 이를 더 조심스럽게 비교하는 UI 장치이며 원자적 서버 CAS가 아니다. 응답이 불확실한 요청의 재시도는 기존 operation/body 그대로 수행한다. 재적용은 사용자가 바꾼 필드만 유지하고 다른 기기의 미편집 최신 점수·메모·시각을 채택한다.

전일18–당일18 KST/26px 시간축, 원본 기상/예정일과 nap 시작 현지일 귀속, 원본 timezone·offset·초 및 DST 검증을 유지한다. nap 표시 최소40px와 실제 점유선은 서로 다른 개념이다. 감지·sync/DB schema/API action/protocolVersion을 이 웹 개편의 후속 단계라는 이유로 변경하지 않는다.
