Reorder holds the existing workspace lock, verifies expected current ordered IDs and full membership, then updates only the ordering key. Initial/unlisted documents use immutable creation order and append after persisted members, so body/title saves do not reorder.

Switching/closing operational notes flushes registered editors first and retains UI on error. Both desktop rails remain visible; constrained center stacks the two panes.
